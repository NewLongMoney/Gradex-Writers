## ✍️ Step 5: Create Your First Article

1. **Click "+ New Article"**

2. **Fill in the form:**
   ```
   Title: 10 Essential Tips for Academic Writing Success
   
   Excerpt: Master the art of academic writing with these proven strategies that will help you excel in your studies.
   
   Content: 
   Academic writing is a crucial skill for students at all levels. Here are 10 essential tips to improve your academic writing:

   1. Start with a clear thesis statement
   2. Create an outline before writing
   3. Use credible sources and cite properly
   4. Write in a formal, objective tone
   5. Use topic sentences for each paragraph
   6. Support claims with evidence
   7. Avoid plagiarism at all costs
   8. Proofread and edit carefully
   9. Follow formatting guidelines
   10. Seek feedback from peers or instructors

   By following these tips, you'll be well on your way to producing high-quality academic papers that earn top grades.
   
   Category: Academic Writing
   Author: Gradex Writers
   Image URL: (leave blank or add any image URL)
   Status: Published
   ```

3. **Click "Save Article"**

4. **Success!** You'll see your article in the dashboard

### Common Questions & Answers:

**Q: Can I add images to articles?**
A: Yes! Add any image URL in the "Image URL" field.

**Q: Can I save drafts?**
A: Yes! Set status to "Draft" and it won't appear on the public blog.

**Q: Can I change the categories?**
A: Yes! Edit the category dropdown in `admin/dashboard.html` and `blog.html`.

**Q: Is it secure?**
A: Yes! Uses JWT authentication, password hashing, and protected routes.

**Q: Can I customize the design?**
A: Yes! Edit `css/style.css` to change colors, fonts, spacing, etc.

**Q: How do I deploy this?**
A: See README.md for production deployment instructions.

## 🚨 Troubleshooting Demo Issues

### Server won't start?
```bash
# Make sure you installed dependencies
npm install

# Check if port 3000 is available
# Change port in server.js if needed
```

### Can't login?
- Username: `admin` (lowercase)
- Password: `admin123`
- Check browser console for errors

### Articles not showing?
- Make sure status is "Published" (not "Draft")
- Check browser console for API errors
- Verify server is running

### Styling looks broken?
- Clear browser cache (Ctrl+Shift+R)
- Check that `css/style.css` exists
- Verify no console errors
