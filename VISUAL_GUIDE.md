## 🎨 Typography Hierarchy

```
H1 (Hero Title)
  ↓ 3rem, Bold, Gold
H2 (Section Titles)
  ↓ 2.5rem, Bold, White
H3 (Card Titles)
  ↓ 1.5rem, Semi-bold, Gold/White
Body Text
  ↓ 1rem, Regular, White
Small Text
  ↓ 0.9rem, Regular, White (80% opacity)
```

## 📐 Spacing System

```
Sections:     5rem padding
Cards:        2rem padding
Gaps:         1-2rem between elements
Container:    Max-width 1200px
Margins:      Auto-centered
```

## 🎭 Component States

### Buttons
```
Default:  Gold background, Dark text
Hover:    Darker gold, Lift up
Active:   Pressed down
Disabled: 60% opacity
```

### Cards
```
Default:  Light blue background
Hover:    Gold border, Lift up
Active:   Click to open/edit
```

### Forms
```
Default:  Dark blue background
Focus:    Gold border
Error:    Red border + message
Success:  Green checkmark
```
